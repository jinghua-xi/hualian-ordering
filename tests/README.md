# 登录与询价测试

在本地项目目录运行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tests/test_accounts.py
```

测试使用临时 SQLite 库、演示模式和本机随机端口，不读写线上订单，不发送邮件。覆盖采购员订单隔离、采购员越权、普通销售不能管理账号、管理员派发账号、登录跳转、重置及停用后登录失效、联系方式缺失及格式错误、异常数量、交期限制、询价编号、重复提交及重复转单。

本次另在浏览器验证了新客户入口、采购车、缺少联系方式的提示、询价编号回执、销售询价列表和管理员账号管理页。

复购检查还覆盖：只能复制本人订单、旧交期清空、数量保留、历史共享货号的颜色正确映射、目录下架商品提示。浏览器另验证主界面入口、历史行按钮、导入采购车及已有采购车的追加/取消保护。


智能粘贴解析测试：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tests/test_paste.py
```

覆盖单一交期共用、多交期对应、缺数量/交期、Excel列解析、中文数量、日期与尺寸/货号区分、负数和小数等异常数量、错误日期、歧义商品、单位冲突、重复栏目及备注数字干扰。接口测试还覆盖权限、模型编造原文/超时后的降级。浏览器验证补全提示、只填空白交期、保留不同交期和现有采购车。

界面重排后在本地浏览器完成：AI咨询/收起、粘贴识别/收起、单项选品仍保持第一步、加入采购车后第二步、临时客户提交后回执可见且第三步、继续询价后两栏恢复与第一步。验证商品填写与采购车等宽并排，批量交期三个控件纵坐标一致且位于核对勾选之前。该测试使用本地演示库，无线上测试订单或邮件。

采购车批量交期在本地浏览器验证：统一全部商品日期、只补空白日期、少于七天拒绝且原值保留、同货号相同交期多条记录允许保留、刷新后单项日期保留。没有提交线上订单。

新增重复明细集成测试：采购员订单与新客户询价允许同货号同交期多条明细；保留不同数量和备注；重复请求返回原编号；销售转单和Excel保留独立行；模拟旧唯一索引迁移并确认旧订单、备注和已发送邮件状态原样保留。浏览器完成两条同SKU同交期导入、批量统一日期及最终询价提交。

SSH部署传输测试：`PYTHONDONTWRITEBYTECODE=1 python3 tests/test_deploy_transport.py`。验证首次临时断开可重试、主机公钥校验失败不重试、远程部署命令不重放、SCP和远端执行共用唯一私有控制套接字并在结束时关闭。

邮件通知设置测试：`PYTHONDONTWRITEBYTECODE=1 python3 tests/test_notification_settings.py`。使用独立临时库和模拟 SMTP，覆盖采购员/未登录用户禁止访问、销售可配置、跨站请求拒绝、异常开关与邮箱格式/邮件头注入拒绝、并发修改冲突、数据库重新初始化保留设置、关闭后不占用发送重试、重新启用后使用新收件地址并保留 Excel 附件、已发送订单不重发，以及已开始发送的邮件使用领取任务时的收件地址。未向真实邮箱发信。

后台界面在本地浏览器验证：账号表单一行排列、账号信息与重置/启停按钮对齐、销售页导航统一靠右、通知拨片自动保存、收件邮箱保存并刷新保留，以及手机宽度下页面无水平溢出。账号权限和密码重置由原账号集成测试回归。

权限补查：只允许公开的目录与时间接口使用访客路径映射；采购员通过 `/api/guest/` 拼接后台路径不能读取账号、订单或通知设置，已加入回归测试。

后台摘要与弹窗：在本地隔离演示库验证20条商品的询价与订单均只显示一条摘要，详情为居中原生对话框，背景变灰模糊；支持关闭按钮、Esc、点击背景关闭，弹窗内滚动且手机不超出屏幕。订单状态修改后可撤销最近一次修改，关闭再打开卡片仍可撤销；完整刷新页面后不保留该页的撤销记录。采购员自己的历史订单仍保持只读和复购入口。

询价不再需要单独点击转单按钮。统一使用四种订单状态；首次从未确认改为其他状态时，在同一事务中创建正式订单、保存选定状态并关联询价，默认保留不同商品交期，可在首次确认前统一改期。测试覆盖重复请求不重复转单、两个列表共享状态、过期状态请求拒绝、异常交期和事务中断时订单/关联/邮件队列一同回滚。撤销只恢复状态，不移除已生成的订单号。

账号测试新增4/18位边界接受、3/19位拒绝；旧长密码仍可登录。普通销售对账号页面及创建/重置/启停接口全部返回403。浏览器用独立演示账号验证启停后正常刷新，修复账号数组覆盖刷新函数引发的“accounts is not a function”。未修改线上账号或发送测试邮件。

安全与客户绑定：`PYTHONDONTWRITEBYTECODE=1 python3 tests/test_security.py`。独立临时数据库覆盖独立管理员入口、普通销售越权拒绝、客户名称伪造与历史快照、绑定持久化和旧表兼容、第五次失败验证码、跨浏览器/过期/重放、Basic认证绕过、并发登录与限流、公开搜索关键词脱敏/链接过滤/缓存及联网失败降级。验证码验证只用模拟固定挑战，不通过浏览器破解真实验证码。

浏览器验证管理员名称修改、采购员名称只读、智能粘贴Qwen默认开启、第五次失败后图片正常显示。没有创建线上测试订单、修改真实绑定名称或发送邮件。
