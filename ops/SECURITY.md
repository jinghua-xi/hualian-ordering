# 登录、客户绑定与联网选型

管理员专用入口：`/admin/login`，登录后进入账号管理。客户入口 `/` 不接受管理员口令；销售可从 `/sales/login` 登录。后端仍逐次检查角色，只有管理员可以创建、重置、启停账号和修改客户名称。独立网址不替代权限检查。原部署健康检查通过受保护的Basic Auth接口执行，不使用浏览器登录表单。

登录失败按账号累计，15分钟观察窗口，第五次失败后显示图片验证码；后续尝试必须提交与浏览器Cookie绑定、五分钟有效、一次性的验证码。十次密码失败后短暂限制一分钟；同一连接来源每分钟最多120次未成功登录尝试。账号计数独立于IP，避免更换IP直接绕过；不信任访客提交的X-Forwarded-For。优云代理可能使多个访客共享来源地址，来源限流阈值因此宽于账号限制。图片验证码提供基本自动化阻力，不能承诺阻止OCR、代理池或DDoS，尚未接入MFA或专业WAF。

计数在数据库中保存，重启不清空；过期计数和图片会清理。密码不回显，PBKDF2保存内部账号密码，比较使用恒定时间摘要比较。页面设置CSP、禁止被其他页面嵌入、限制浏览器摄像头和定位权限。会话使用Secure、HttpOnly、SameSite Cookie，原有跨站请求检查继续生效。

客户名称另存于`account_profiles`，不修改旧accounts表的列数。旧账号默认绑定账号名，由admin改为实际客户名称。采购员前端只读，后端忽略伪造客户名并从账号绑定读取；新名称影响新订单，历史订单保留提交时名称。临时访客仍自行填写名称及联系方式。

采购建议可通过Bing中国区公开RSS搜索获取摘要，直接使用已核验的cn.bing.com端点，禁止自动跳转至任意域名。搜索请求只包含预设的品类、材料和用途关键词，不发送原文、账号、客户名称、联系方式或订单数量；不根据网页指令抓取任意URL。响应大小、超时、链接协议、缓存条数均有限制，拒绝DTD/实体，过滤常见购物平台。外部摘要作为不可信资料传给Qwen，只生成一般采购说明；订单字段、商品候选仍由本地目录和服务器校验控制。搜索失败明确提示并回退，不冒充已联网。公共RSS没有商用搜索API的可用性保证，后续可替换为有服务保障的搜索API。

验证码和限流参考 [OWASP Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。这次验证覆盖功能和常见绕过路径，不代表完整渗透测试。当前管理员仍沿用服务器原有口令，默认弱口令应由管理员私下更换。
